# Practice - Part 2

## Your profile page

We are going to make this README.md appear on your profile page.

- On the top menu to the far right, click on Settings
- Under repository name, replace `dd-example` with your GitHub account name then click Rename
- On the far right, click `Edit README`
- Add some more details, such as a a table or image.
- When you've committed your changes, click on your icon in the upper right corner and click on Profile

You should see your README being rendered on your profile page.

## Your own site - GitHub Pages

- On the top menu to the far right, click on Settings
- Under repository name, add `github.io` to your GitHub account name then click Rename
- Count to 30 or so, slowly
- Visit the site `{your account name}.github.io`

You should see your README as a web page without all the GitHub additions.

## Next steps

If you are not ready to display your details either on your profile or on GitHub pages, rename the repo to something else or delete it.
If you are ready, edit away.
