# Pratice - Part 1

We are going to create a Readme.md file in a new repo and edit it.

## Create the repo

- Log into GitHub
- Click the User Navigation Menu in the upper right of the page ( your icon )
- Scroll down and click on Repositories
- Click the big, green New button to create a new repo
- Choose an owner, if that option exists, and select your name
- Use "dd-example" for the repo name
- Click "on" next to `Add README`
- Click the big, green `Create tepository` button
