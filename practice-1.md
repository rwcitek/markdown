# Pratice - Part 1

We are going to create a README.md file in a new repo and edit it.

## Create the repo

- Log into GitHub
- Click the User Navigation Menu in the upper right of the page ( your icon )
- Scroll down and click on Repositories
- Click the big, green New button to create a new repo
- Choose an owner, if that option exists, and select your name
- Use "dd-example" for the repo name
- Click the "on" switch next to `Add README`
- Click the big, green `Create repository` button

## Edit the README.md

- Click on the README.md file
- Click on "Edit this file" ( the pencil icon )
- Erease any existing text
- Create a level 1 heading with your name, e.g. `# Hi, I'm {your name}` 
- Click the big, green "Commit Changes" button in the upper right of the page
- In the pop-up window, enter a commit message, or let Copilot fill it in
- Click the big, green "Commit Changes" button below the pop-up window
- Repeat editing the README.md file, filling in some more information about yourself.  Here's a template you can use:

```markdown
## About me
- 

## How to Reach Me
- LinkedIn: 
- GitHub: 

```
